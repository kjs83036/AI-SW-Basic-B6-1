# 리소스 정리 체크리스트

> 실습 종료 후 과금 방지를 위해 아래 항목을 위에서 아래 순서대로 수행하고 체크한다.
> **리소스 간 의존 관계가 있으므로 순서를 반드시 지킨다.**

---

## 정리 순서 및 체크리스트

### 1. EC2 관련

- [ ] **EC2 인스턴스 종료(Terminate)**
  - EC2 → 인스턴스 → 인스턴스 선택 → 인스턴스 상태 → **종료**
  - 상태가 `terminated`로 변경됨 확인 (stopped 아님)

- [ ] **Elastic IP 릴리스**
  - EC2 → 탄력적 IP → 사용하지 않는 EIP 선택 → **주소 릴리스**
  - 미사용 EIP는 시간당 과금 발생함

- [ ] **EBS 볼륨 삭제**
  - EC2 → 볼륨 → 상태 `available`인 볼륨 삭제
  - EC2 종료 시 "종료 시 삭제" 옵션 활성화했으면 자동 삭제됨 (확인 필요)

---

### 2. 로드밸런서 / NAT Gateway (생성한 경우)

- [ ] **ELB/ALB 삭제** (생성한 경우)
  - EC2 → 로드밸런서 → 삭제

- [ ] **NAT Gateway 삭제** (생성한 경우)
  - VPC → NAT 게이트웨이 → 삭제
  - 삭제 완료까지 수분 소요

---

### 3. VPC 구성 요소 (순서 중요)

- [ ] **Internet Gateway Detach 및 삭제**
  - VPC → 인터넷 게이트웨이 → VPC와 연결 분리(Detach) → 삭제

- [ ] **서브넷 삭제**
  - VPC → 서브넷 → `public-subnet` 삭제

- [ ] **라우팅 테이블 삭제** (메인 RT 외 추가 생성한 경우)
  - VPC → 라우팅 테이블 → 커스텀 RT 삭제

- [ ] **보안 그룹 삭제**
  - VPC → 보안 그룹 → `infra-sg` 삭제 (기본 SG는 삭제 불가)

- [ ] **VPC 삭제**
  - VPC → VPC → `infra-vpc` 삭제
  - 위 구성 요소 모두 삭제 후 가능

---

### 4. 기타 리소스

- [ ] **키페어 삭제** (EC2 → 키페어 → `infra-keypair` 삭제)
  - 로컬 `.pem` 파일도 삭제

- [ ] **IAM 사용자 삭제** (재사용 계획 없으면)
  - IAM → 사용자 → `infra-practitioner` → 삭제
  - 삭제 전 액세스 키가 있으면 먼저 비활성화/삭제

---

### 5. RDS (생성한 경우)

- [ ] **RDS 인스턴스 삭제**
  - RDS → 데이터베이스 → 삭제 (최종 스냅샷 생략 선택 가능)

---

### 6. 최종 확인

- [ ] **Billing Dashboard 확인**
  - AWS 콘솔 오른쪽 상단 → 계정 → **청구 및 비용 관리**
  - **청구서** 또는 **비용 탐색기**에서 미정리 과금 항목 없음 확인
  - **무료 티어 사용량**에서 초과 항목 없음 확인

---

## 정리 완료 기준

아래 항목이 모두 확인되면 정리 완료로 본다:

| 리소스 | 상태 | 확인 일시 |
|--------|------|---------|
| EC2 인스턴스 | Terminated | |
| EBS 볼륨 (미사용) | 삭제됨 | |
| Elastic IP | Released | |
| Internet Gateway | 삭제됨 | |
| 서브넷 | 삭제됨 | |
| VPC | 삭제됨 | |
| 보안 그룹 | 삭제됨 | |
| 키페어 | 삭제됨 | |
| Billing Dashboard | 과금 항목 없음 | |

---

> **참고**: EC2 종료 후에도 EIP, EBS 미사용 볼륨이 남으면 계속 과금된다.
> Billing Dashboard를 다음 날 다시 한 번 확인하는 것을 권장한다.
